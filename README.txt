# Chinemerem & Chinonso Wedding Invitation Website

Open `index.html` in a browser to preview the website.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — countdown timer
- `assets/wedding-invitation.jpg` — supplied wedding invitation image

## Put it online for free
This is a static website. It can be published with GitHub Pages, Netlify, or another static-hosting service without a server.
